# Dcitos Corporate Website

A modern, responsive corporate website built with **Next.js 16**, **React 19**, **Tailwind CSS**, **Framer Motion**, and **GSAP**. The website showcases Dcitos' services, company information, values, and contact details with a premium user experience and smooth animations.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/dcitos-task.git
```

Go to the project directory

```bash
cd dcitos-task
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 📦 Build for Production

```bash
npm run build
```

Run production build

```bash
npm start
```
